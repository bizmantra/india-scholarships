# Brief for AGY: 14 scholarships that may have no fixed deadline (rolling or ongoing)

Written 2026-10-22 (backlog item for the deadline clean-up, CNT-111). Research only: see the rules.

## Goal
Each of the 14 scholarships below has a note on our site saying applications are accepted "on an ongoing basis", "year-round" or "continuously", or something similar. But they also carry an old estimated date that has been taken off the page. For each one, find what the **official** page says now, so we can show students the right thing: a fixed date, "open all year", "not announced", or "closed".

## What to decide for each scholarship
Use exactly one verdict:

| Verdict | Meaning | Needs |
|---|---|---|
| `ROLLING` | The official page says applications are accepted all year / continuously / on an ongoing basis, with no closing date | URL + quote that says so |
| `FIXED_DATE` | The official page gives a student application deadline for the current cycle | URL + quote + the date as `YYYY-MM-DD` + which cycle (e.g. 2026-27) |
| `NOT_ANNOUNCED` | The official page says the cycle has not opened or the dates are not yet announced | URL + quote |
| `CLOSED` | The official page says applications are closed, or the scheme has ended | URL + quote |
| `NOT_FOUND` | No official page states any of the above | list the pages you tried |

Our own note on the site is **not** evidence: it is what we are trying to check. A scholarship can be rolling for one group of students and fixed for another: say so in the quote column and use `FIXED_DATE` only if the date applies to the students this scheme is for.
