# Canada, Batch 2: universities, programmes and scholarships (official sources only)

All pages were read on **2026-11-28** (28 November 2026). Every figure on the draft pages is listed below with the exact words from the page (copied from the page text, with whitespace joined; table cells read left to right) and its URL. Study permit and Quebec rules and the Bank of Canada rate are in `ca-visa-facts.md`. This file covers Batch 2. Where a quote is shown as a long run of words, it is a table or list read as plain text.

Nothing here is filed. The proposals are JSON files and one `.cjs` script that has not been run against any database.

**Money to show.** UBC is a 10-month programme, so we give a full sum. For the other five we give the programme price and IRCC's (or Quebec's) living amount as separate lines, and tell the reader to ask for the first-year tuition. This is a policy choice to confirm.

**Fee year.** Fees are the latest published: September 2026 for Toronto, 2026/27 for SFU and Concordia (cohort rate), the Winter 2027 schedule for Waterloo, the Summer 2027 class for McGill, and the page figure for UBC. None is a confirmed fee for a 2027 start unless it says so.
