# Australia Student visa facts for Indian students (master's), official sources only

All pages were read on **2026-11-28** with a real browser (the Home Affairs pages load their text with JavaScript, so a plain fetch shows almost nothing). No agent, coaching, blog or news-site figure is used. "NOT PUBLISHED" means no official page I could read gives it.

Sources: Department of Home Affairs (`immi.homeaffairs.gov.au`), Study Australia (`studyaustralia.gov.au`, run by Austrade), Reserve Bank of Australia (`rba.gov.au`), Federal Register of Legislation.

The RBI/FBIL reference rate does not cover AUD, so the RBA rate is the official source. It changes daily, so it is not stored as an `sa_facts` row (a stored quote would stop matching the next day). Every rupee figure on the pages says which rate it uses.

## Conflicts and gaps

- **Calculator date conflict:** the Study Australia "Living and education costs" page says the calculator costs "were last updated November 2023", while the calculator itself says November 2025. The pages use the calculator's own November 2025 wording.
- **The calculator's own rupee rate** is a fixed 56.75 in its code. It is out of date against the RBA 61.80, so it is not used.
- **OSHC price:** NOT PUBLISHED on any government page I read (the comparison tool is dynamic). The pages tell readers to get a quote.
- **Tuition ranges for a master's:** NOT PUBLISHED as a national figure. Study Australia says fees vary by provider, level and location. University fees belong to the university pages (second batch).
- **Visa pricing table row for subclass 500:** the table on `/fees-and-charges/current-visa-pricing` is paged and I could not open the subclass 500 row. The AUD 2,500 comes from the Student visa page itself.
- **Evidence level / document list for Indian passports:** NOT PUBLISHED as a list. It comes from the Document Checklist Tool (an interactive tool), so the pages send readers to it.
- **Minimum wage:** NOT USED. `fairwork.gov.au` returned a server error when read.
- **Source checker:** Home Affairs returns HTTP 403 to the checker's user agent, and the facts it needs sit in a script block that the checker's text step drops. Only the two fee quotes are in a part of the page the checker can read, so no registry entries were added (see `au-batch1-notes.md`).
